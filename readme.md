## 📌 Sobre o Projeto

O **Portal de Entretenimento Digital** é um site desenvolvido como projeto prático no curso de **Desenvolvimento de Sistemas da ETEC**. 

O objetivo do portal é organizar e recomendar conteúdos de entretenimento — como **filmes, séries, podcasts, jogos e ferramentas tecnológicas** — com foco no tema de **Inteligência Artificial (IA)** e suas implicações na sociedade e no futuro.

---

## 🚀 Tecnologias e Conceitos Aplicados

Neste projeto, apliquei conceitos essenciais de estruturação web e estilização visual:

* 🏗️ **HTML5 Semântico:** Estruturação da página utilizando divisões (`<div>`), títulos de diferentes níveis (`<h1>`, `<h2>`, `<h3>`) e parágrafos (`<p>`).
* 🎨 **CSS3 Interno e Inline:** Aplicação de estilos diretos para alinhamento, cores e tamanhos de fonte.
* 🧹 **CSS Reset (`reset.css`):** Uso do padrão Eric Meyer para remover inconsistências de margens e espaçamentos entre diferentes navegadores.
* 🖼️ **Imagens Responsivas:** Inserção de capas e logos com atributos `alt` para acessibilidade e limitação de dimensões via CSS (`max-width`).
* 📐 **Layout em Colunas:** Organização do conteúdo em três seções principais (esquerda, centro e direita) integradas ao arquivo `estilo.css`.

## 🖥️ Como Executar o Projeto

Por ser um site estático (HTML5 e CSS3), não é necessário instalar gerenciadores de pacotes ou servidores:

1. **Faça o clone ou download do repositório:**
   ```bash
   git clone https://github.com/lucas-fersa/segundo_site.git
   ```
2. **Navegue até a pasta do projeto.**
3. **Abra o arquivo `index.html`** no seu navegador de preferência (Google Chrome, Firefox, Edge, etc.).
